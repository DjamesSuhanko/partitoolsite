## Partitool é a ferramenta dos sonhos dos músicos!

Quantas vezes procuramos por partituras para um instrumento transpositor específico, mas aquelas músicas famosas só são escritas para altura de orquestra. Daí pegamos um PDF e, se quisermos algo próprio para nosso instrumento, precisamos escrever tudo manualmente em um editor como o [MuseScore Studio](https://musescore.org/pt-br/download). Mas e se pelo menos fosse possível ter um "rascunho" ou até um arquivo de música completo, para só fazer o transporte? - Aí que entra o **Partitool**

## Conversão de formatos

Existem diferentes arquivos que podem ser convertidos para música. PDF é um formato bastante comum e, quando não for uma foto ou o escaneamento de uma partitura, tende a ser formato gerado pelos editores de música.

Quando a origem do arquivo PDF advém de um programa de notação musical, as chances de converter novamente para partitura são extremamente altas! Se não em sua integridade, pelo menos um rascunho para dar um "retoque" no editor de sua preferência. E para isso, o formato de saída da conversão e o formato global de música: O MusicXML.

## E outros formatos...

Também é possível converter a partir de arquivos Lilypond. Em breve, outros conversores serão implementados, conforme o aplicativo evului e melhora seu reconhecimento.
